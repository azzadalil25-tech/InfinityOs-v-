Privasi & Ketentuan

Sebelum menyiapkan Infinity OS, tinjau ringkasan privasi, ketentuan penggunaan, dan petunjuk perangkat.

Kebijakan privasi

Infinity OS ini adalah prototipe HTML. Preferensi demo dapat disimpan di browser. Kamera memerlukan izin browser. Fitur jaringan, SIM, baterai, keamanan, dan update merupakan simulasi.

Jika kamu mengaktifkan Infinity AI online, pertanyaan akan dikirim ke endpoint AI yang kamu pilih. API key dimasukkan langsung di halaman dan tidak boleh dibagikan; jangan gunakan key sensitif pada file yang dibagikan.

Ketentuan penggunaan

Gunakan prototipe ini untuk eksperimen UI. Fitur simulasi bukan pengganti layanan sistem Android, pemeriksaan keamanan, atau dukungan perangkat resmi. Layanan pihak ketiga terbuka di situs mereka sendiri.
